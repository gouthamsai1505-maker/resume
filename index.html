Personal Finance Manager

A secure income and expense tracker featuring transaction management, searchable history, and a responsive financial dashboard.

Node.jsMongoDBSSRSessionsSecurityIndexing
Read project highlights +
  • Income and expense CRUD, server validation, allow-listed query parameters, search, filtering, sorting and 10-item pagination.
